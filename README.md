# Pak Solar Tech
A comprehensive solar energy solutions platform for households and businesses in Pakistan.

## Live Demo
[paksolartech.com](https://paksolartech.com)

## Tech Stack
Next.js 14 · TypeScript · Tailwind CSS · MySQL

## Key Features
- **Solar Calculator**: Estimate system costs and monthly savings tailored for Pakistan's specific energy needs.
- **Product Marketplace**: A curated catalog of Tier-1 solar panels, high-efficiency inverters, and reliable batteries.
- **Service Management**: Professional installation services with end-to-end net-metering support and documentation.
- **Admin Dashboard**: Advanced management system for products, educational blogs, and site-wide FAQs.
